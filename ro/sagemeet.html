Întrebări frecvente

FAQ

Este SageMeet gratuit?
Da — SageMeet este gratuit pe App Store. Tu îți aduci propria cheie OpenAI pentru funcțiile AI (transcriere Whisper și rezumare GPT-4o), deci plătești direct OpenAI pentru utilizare, nu un abonament către noi.
Trimite SageMeet audio-ul către OpenAI?
Doar când rulezi explicit o funcție AI (transcriere, rezumare, căutare semantică) și doar prin propria ta cheie OpenAI. Înregistrarea în sine este complet locală. Modul Privat dezactivează orice cerere externă.
Ce este BYOK?
Bring Your Own Key. În loc de abonament, îți aduci propria cheie API OpenAI. Cheia este stocată în Keychain-ul iOS și folosită doar pentru a autentifica cererile pe care tu le inițiezi. Noi nu avem backend, deci nu putem să-ți facturăm.
Folosește OpenAI înregistrările pentru antrenare?
Nu. Termenii API ai OpenAI specifică explicit că datele trimise prin API nu sunt folosite pentru antrenarea modelelor. OpenAI este certificat sub EU-US Data Privacy Framework.
Unde sunt stocate înregistrările?
Înregistrările, transcrierile și notele generate de AI stau pe iPhone-ul tău, cu sincronizare iCloud opțională către celelalte dispozitive Apple. Sagelight Studio nu primește și nu stochează niciodată datele ședințelor tale.

Reține totul. Privat.

Gratuit. Tu îți aduci cheia OpenAI. Pe iPhone, iPad și Mac. Conform GDPR by design.
